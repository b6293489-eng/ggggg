# Music Factory — передача задачи в Codex на Windows

Готовый запрос для нового чата находится в `WINDOWS-CODEX-PROMPT.txt`. Приложение версии 2.2.3 использует Playwright и установленный Google Chrome; расширение Music Factory Bridge больше не участвует в очереди. Вход выполняется в обычном Chrome без Playwright, после чего сохранённый профиль проверяется скрытой автоматизацией без второго окна.

## Уже готово

- Electron-приложение для macOS Apple Silicon и Windows x64.
- ACE-Step 1.5: последовательная генерация, Turbo, batch 1; профиль RTX 4060 8 ГБ с CPU offload.
- Быстрый и экономный режимы памяти.
- Три аккаунта: Бос (`bos-423483424`), Gleb fps (`nn1v-680019554`), Rivi (`rivi-135338423`).
- Пакетный публичный альбом: title → Public → Amplify → подтверждение → нижняя Upload.
- Отдельная монетизация после подтверждённой публичной ссылки и подтверждения прав пользователем.
- Отдельные постоянные Playwright-профили с безопасной проверкой загрузчика без передачи файлов.

## Что сделать на Windows

1. Распаковать Windows ZIP полностью и запустить `Music Factory.exe` в нативной Windows, не в WSL.
2. Установить Google Chrome, если его нет.
3. В «Настройки» → «Настроить Windows» найти ACE-Step автоматически или выбрать корень вручную. Нужны одновременно:
   - `acestep\acestep_v15_pipeline.py`
   - `.venv\Scripts\python.exe`
4. Проверить профиль RTX 4060 8 ГБ, Turbo, batch 1, CPU offload и нужный режим памяти.
5. Запустить ACE-Step и сделать один локальный тестовый WAV без публикации.
6. При наличии резервной копии с Mac восстановить библиотеку.
7. В «Аккаунты» для Бос, Gleb fps и Rivi по очереди открыть обычный Chrome Factory, дать пользователю самому войти, полностью закрыть это окно и нажать «Проверить вход».
8. Убедиться, что все три карточки показывают «Playwright проверен · загрузчик найден».
9. Не запускать реальную публикацию или монетизацию без отдельного явного действия пользователя.

## Команды

```powershell
npm install
npm test
npm run build:windows
```

Сборка появляется в `..\releases\v2.2.3\Music Factory-win32-x64`. При ошибке открыть «Настройки» → «Диагностика» и проверить `desktop.log` и `logs\ace-step.log`. Не удалять WAV, JSON, библиотеку или состояние. При неясном результате SoundCloud не повторять загрузку автоматически.
