# Music Factory Bridge — устаревший режим

Начиная с Music Factory 2.2.3 активная очередь работает через встроенный Playwright. Это расширение сохранено только для диагностики старых установок; устанавливать, обновлять и подключать его больше не нужно.

Локальный мост для уже залогиненных профилей Chrome на macOS и Windows. Расширение само получает задания из запущенной Music Factory на `127.0.0.1:8788`; API-ключ SoundCloud, пароль, разрешения Codex, запись экрана и macOS Accessibility ему не нужны.

## Подключение один раз

1. Запусти Music Factory. В разделе «Аккаунты» скопируй код нужного аккаунта.
2. Открой соответствующий профиль обычного Google Chrome. Бос → Бос; Gleb Ohai → Gleb fps; Boner Kurva → Rivi. Проверь, что SoundCloud в этом профиле уже открыт под нужным пользователем.
3. Открой `chrome://extensions`, включи «Режим разработчика», нажми «Загрузить распакованное расширение» и выбери эту папку `extension` (именно папку с `manifest.json`).
4. Нажми иконку Music Factory Bridge, выбери аккаунт этого профиля, вставь его код и нажми «Подключить».
5. Повтори в двух других профилях. Оставь Chrome запущенным; Factory запускает аккаунты по очереди. Активное задание откроет отдельную видимую вкладку.

Расширение проверяет связь каждые 30 секунд. Если Chrome полностью закрыт, код профиля отозван или локальная Factory остановлена, задания ждут подключения. Установка распакованного расширения выполняется пользователем: обычное приложение не может незаметно установить его в Chrome.

## Публикация

В Factory назначь треки аккаунтам и запусти публичную публикацию. Профиль определяется сохранённой привязкой расширения, которую пользователь лично проверяет при подключении; меню SoundCloud не используется для ненадёжной повторной проверки. Расширение передаёт выбранную пачку одним `FileList`, заполняет название альбома, выбирает Public, нажимает `Amplify tracks`, ждёт точное подтверждение `We'll analyze your tracks for recommendation` и только затем один раз нажимает нижнюю `Upload`. Приватные черновики не создаются. Ссылки и статус результата возвращаются в Factory.

Если Amplify вызывает оплату, обновление подписки или дополнительное окно, расширение ничего не покупает и не публикует пачку. Оно оставляет страницу открытой и сообщает причину в Factory.

## Монетизация

Укажи в Factory сведения для заявки: подтверждение прав, автора или представителя авторов, юридическое имя, имя артиста, рейтинг содержимого и ISRC либо отсутствие ISRC. Расширение не выводит авторство или права из факта AI-генерации.

Обрабатываются только конкретные опубликованные треки задания. Перед отправкой расширение проверяет выбранный трек в форме SoundCloud for Artists. `submitted` означает отправленную заявку на проверку. Это не обещание одобрения SoundCloud. Если в интерфейсе не виден нужный трек или обязательные поля, задание остановится с объяснением в Factory.

## Остановка и восстановление

После сбоя загрузки, обновления страницы, CAPTCHA или отключения сети расширение не загружает пачку повторно автоматически. Статус `uncertain` означает, что действие могло пройти: сначала проверь сохранённую вкладку/ссылки в Factory. Перезапуск Chrome сохраняет код подключения и журнал уже запущенных заданий.

## Проверка этой версии

Проверены тестами: границы аккаунтов, проверка ссылок, передача метаданных без выдуманных подтверждений, защита от повторного запуска, сохранение контрольной точки до загрузки, повтор доставки отчёта с одним `reportId`, отказ от ложного завершения. Реальные публичные загрузки и монетизация этой версией не выполнялись: SoundCloud может менять структуру интерфейса. При несовпадении расширение сообщает конкретное неподдержанное поле и останавливается. Первый запуск нужен для проверки совместимости с текущей формой аккаунта.

Полный набор тестов: `npm test` из папки исходников приложения.

## Протокол локального сервера

Запросы только к `http://127.0.0.1:8788`: Bearer-код конкретного аккаунта и обязательная совместимая версия Bridge, `POST /bridge/heartbeat`, `GET /bridge/job?accountId=...`, `POST /bridge/report`, `GET /bridge/audio/:trackId` с `Range`. Аудио возвращается `206` с `Content-Range`; фрагменты по 512 КиБ передаются в изолированный content script, без секретов в DOM. Файлы и URL произвольных сайтов запрашивать нельзя. `reportId` сохраняется до передачи отчёта и повторяется при сетевом сбое.

Официальные документы Chrome: [сетевые запросы расширений](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests), [изолированные content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts), [передача сообщений](https://developer.chrome.com/docs/extensions/develop/concepts/messaging).
