Старого чата у тебя нет. Полностью прочитай AGENTS.md, README-RU.md и WINDOWS-CODEX-HANDOFF.md. Нужно не только объяснять, а безопасно настроить и проверить Music Factory 2.2.3 на этом компьютере. Пароль и коды подтверждения я ввожу сам.

ЦЕЛЬ

1. Импорт JSON-плана для аудитории USA.
2. Генерация WAV через ACE-Step 1.5.
3. Распределение между Бос, Gleb fps и Rivi.
4. Публичная пакетная загрузка через отдельные профили Playwright.
5. Album title → Public → Amplify tracks → подтверждение анализа → одна нижняя Upload.
6. Монетизация отдельным этапом только после публикации, заполнения данных и моего подтверждения прав.

ФАЙЛЫ

- Music Factory 2.2.3 Windows.zip нужно распаковать полностью. Нельзя запускать EXE внутри ZIP.
- Music Factory 2.2.3 Source.zip нужен для диагностики и исправлений.
- Резервная копия с Mac может содержать JSON и audio. Она не содержит пароли, cookies, путь ACE-Step или подтверждение прав.

БЕЗОПАСНОСТЬ

- Без моего отдельного явного действия не публикуй реальные треки, не нажимай финальную Upload и не отправляй монетизацию.
- Можно сделать один локальный тест генерации.
- Не покупай подписки и не подтверждай права вместо меня.
- На CAPTCHA, оплате, проверке личности, лицензии, правах или незнакомой форме остановись.
- Не удаляй WAV, JSON, библиотеку и состояние.
- После возможной передачи файлов не повторяй загрузку при неясном результате: сначала исключи дубликат.

НАСТРОЙКА

1. Работай в нативном PowerShell, не в WSL.
2. Распакуй ZIP и запусти Music Factory.exe. Рядом должны остаться resources, DLL и PAK.
3. В «Настройки» → «Настроить Windows» нажми «Найти автоматически».
4. Валидный корень ACE-Step содержит `acestep\acestep_v15_pipeline.py` и `.venv\Scripts\python.exe`. Если окружения нет, не подменяй его случайным системным Python.
5. Проверь RTX 4060 8 ГБ, PyTorch, Turbo, batch 1, CPU offload. Для первого теста выбери экономию памяти.
6. Запусти ACE-Step, дождись «Сервис отвечает» и создай один короткий WAV. Реальную публикацию не запускай.
7. Если есть резервная копия, восстанови её через Factory и проверь названия, WAV и назначения.

SOUNDCLOUD ЧЕРЕЗ PLAYWRIGHT

Расширение Chrome не нужно. Music Factory использует установленный Google Chrome и создаёт три отдельные постоянные папки профилей.

- Бос → @bos-423483424
- Gleb fps / Gleb Ohai → @nn1v-680019554
- Rivi / Boner → @rivi-135338423

Для каждого аккаунта:

1. В Factory открой «Аккаунты» → нужная карточка → «Войти в SoundCloud» → «Открыть браузер Factory». Вход должен открыться в обычном Chrome без Playwright и remote debugging.
2. Остановись, чтобы я сам ввёл логин, пароль и код.
3. После моего «готово» полностью закрой отдельное окно Chrome Factory и нажми в Factory «Проверить вход».
4. Скрытая проверка должна найти iframe `/n/upload` и `input[type=file]`, не показывая второе окно и не передавая аудио.
5. Убедись, что карточка показывает «Playwright проверен · загрузчик найден».
6. Повтори для всех трёх аккаунтов. Не смешивай профили.
